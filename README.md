# ファラオ 完全日本語版 Windows 11 パッチ

イマジニア発売の「ファラオ 完全日本語版 1.0」CD版をWindows 11でインストールし、日本語でプレイするためのパッチです。このリポジトリでの初版はパッチ v2 です。

## パッチの使い方

このページの **Code → Download ZIP** からZIPを取得し、「すべて展開」します。対象版のCDイメージと、日本語のシステムロケール（コードページ932）およびＭＳ明朝が利用できるWindows環境が必要です。新規インストールには約800 MBの空き容量を確保してください。

### 新規インストール

1. 展開先の `Install.cmd` を開きます。
2. 元のCDイメージの `.ccd` を選びます。同名の `.img` を同じフォルダーに置いてください。
3. インストール先 `%LOCALAPPDATA%\Pharaoh-JP` の `Play.cmd` を開きます。起動時に `Pharaoh.iso` が仮想CDとしてマウントされます。次回も `Play.cmd` から起動します。

### インストール済みのゲームに適用する

1. ゲームを終了して `Patch-existing.cmd` を開き、インストール済みの `Pharaoh.exe` を選びます。
2. ゲームに `Play.cmd` がある場合は、そこから起動します。元のCDから導入した場合は、CDイメージをマウントして `Pharaoh.exe` を起動します。

タイトルやメニューのBGMが鳴らない場合も、ゲームを終了して同じ `Patch-existing.cmd` を実行します。ゲームフォルダーの `Pharaoh.iso`、またはマウントした元のCDから `Audio\Music\setup.mp3` を補います。

更新前の実行ファイルと、適用前から存在した描画DLL・設定ファイル・ライセンス文書は、ゲームフォルダー内の `Win11Patch-v2-backup` に保存されます。

## アンインストール

### このパッチで新規インストールした場合

1. ゲームを終了します。
2. セーブを残す場合は、インストール先の `Save` フォルダーを別の場所にコピーします。
3. エクスプローラーの「PC」で仮想CD `PHARAOH` を右クリックし、「取り出し」を選びます。ゲームフォルダーの `Pharaoh.iso` をマウントしたドライブが対象です。
4. インストール先の `%LOCALAPPDATA%\Pharaoh-JP` フォルダーを削除します。別のインストール先を指定した場合は、そのフォルダーを削除します。

### 既存のゲームからパッチだけを取り除く場合

1. ゲームを終了します。
2. ゲームフォルダー内の `Win11Patch-v2-backup` を開き、入っているファイルをゲームフォルダーにコピーして上書きします。
3. `ddraw.dll`、`ddraw.ini`、`cnc-license.txt` のうち、バックアップにないファイルをゲームフォルダーから削除します。

4. 今回初めて追加された `Audio\Music\setup.mp3` があれば削除します。

この手順でゲーム本体と描画設定をパッチ適用前に戻し、`Save` はそのまま引き継げます。

## 修正内容

- **インストールと起動**。CloneCDのMode 1データトラックからWindowsでマウントできるISOを作成します。CD内のInstallShield 5アーカイブを検証してゲームファイルを展開します。適用する実行ファイルの版とパッチ適用後の内容はSHA-256で照合します。
- **日本語表示**。フォント全体の最大文字幅を各文字の幅として使うと、文字間隔が広がり、ボタンのラベルなどが途中で切れます。使用中のフォントで全角文字「日」の幅を計測し、文字配置と描画用ビットマップの生成にその幅を使います。
- **全画面起動とDirectDraw互換性**。cnc-ddraw 7.1.0を同梱し、元の4:3の縦横比を保つボーダーレス全画面を既定にしました。描画設定にはDirect3D 9を指定しています。`Alt+Enter` でウィンドウ表示と切り替えられます。
- **時間進行**。処理の遅れを次のループに持ち越し、1回のループで最大4回まで更新します。250ミリ秒以上の遅れや4回を超える未処理分がある場合は1回更新して基準時刻を取り直します。更新間隔の下限は16ミリ秒です。マップをスクロールしている間も都市の時間が進み、ゲーム内の速度設定と一時停止は引き続き使えます。
- **タイトル・メニューのBGM**。元のCDに収録されている `setup.mp3` を、ゲームが読み込む `Audio\Music` に展開します。パッチ適用時に同名の曲が既にある場合は、その曲を使用します。
- **旧ウェブサイトへのリンク**。メニューの「ファラオのウェブサイトへ」ボタンから外部サイトを開く処理を無効にしました。

## 動作確認

Windows 11（ビルド26300、日本語システムロケール）でCDイメージから新規インストールし、1920×1080の全画面表示で最初のミッション「ヌブト」に入りました。メニュー、ミッション説明、チュートリアル、都市画面の日本語表示を確認しました。

「ヌブト」で約3秒間ずつ計測した都市シミュレーションの更新回数です。

| ゲーム内の速度設定 | 静止時 | スクロール入力中 |
| --- | ---: | ---: |
| 90% | 約45回/秒 | 約45回/秒 |
| 100% | 約63回/秒 | 約63回/秒 |
