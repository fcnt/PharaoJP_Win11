# ファラオ 完全日本語版 Windows 11 パッチ

イマジニア発売の「ファラオ 完全日本語版 1.0」CD版向けの修正記録です。v1でCDからのインストールと日本語表示に対応し、v2で全画面起動、都市の時間進行、旧ウェブサイトへのリンクを修正しました。このリポジトリには修正内容と使い方を記録しています。

## パッチの使い方

パッチ v2 のZIPと、対象版のCDイメージを用意します。日本語のシステムロケール（コードページ932）とＭＳ明朝が利用できるWindows環境を前提とします。新規インストールには約800 MBの空き容量が必要です。

### 新規インストール

1. パッチのZIPを「すべて展開」し、`Install.cmd` を開きます。
2. CDイメージの `.ccd` を選びます。同名の `.img` を同じフォルダーに置いてください。
3. インストール先 `%LOCALAPPDATA%\Pharaoh-JP` の `Play.cmd` で起動します。起動時に `Pharaoh.iso` が仮想CDとして自動でマウントされます。

### 既存インストールまたは v1 からの更新

1. ゲームを終了して `Patch-existing.cmd` を開き、インストール済みの `Pharaoh.exe` を選びます。
2. v1のインストーラーで導入した場合は、同じ `Play.cmd` で起動します。元のCDから導入した場合は、CDイメージをマウントして `Pharaoh.exe` を起動します。

セーブデータはゲームフォルダー内の `Save` から引き継がれます。更新前の実行ファイルと、適用前から存在した描画DLL・設定ファイル・ライセンス文書は `Win11Patch-v2-backup` に保存されます。元に戻すには、ゲーム終了後にバックアップのファイルを元の場所へ上書きし、今回追加したファイルのうちバックアップに存在しないものを削除します。追加対象は `ddraw.dll`、`ddraw.ini`、`cnc-license.txt` です。

## 修正履歴

### v1

- **インストールと起動**。CloneCDのMode 1データトラックからWindowsでマウントできるISOを作成します。CD内のInstallShield 5アーカイブを検証してゲームファイルを展開し、起動時は仮想CDをマウントして元のCD認識処理を通します。
- **日本語表示**。ゲームがフォント全体の最大文字幅を各文字の幅に使っていたため、文字の間隔が広がり、ボタンのラベルなどが途中で切れていました。使用中のフォントで全角文字「日」の幅を計測し、文字配置と描画用ビットマップの生成にその幅を使います。
- **DirectDraw互換性**。検証環境では元の画面モード切り替えが失敗しました。cnc-ddraw 7.1.0を使ってウィンドウ表示で起動できるようにしました。 [cnc-ddraw ソース](https://github.com/FunkyFr3sh/cnc-ddraw/tree/541b5de)

### v2

- **全画面起動**。元の4:3の縦横比を保つボーダーレス全画面を既定にしました。描画設定はDirect3D 9を指定しています。`Alt+Enter` でウィンドウ表示と切り替えられます。
- **時間進行**。元のゲームは更新が遅れた分を次に持ち越さず、高速設定では処理負荷によって実際の更新ペースが変動しました。v2は経過時間から更新回数を計算し、1回のループで最大4回まで更新して端数を次に持ち越します。250ミリ秒以上の遅れや4回を超える未処理分がある場合は1回更新して基準時刻を取り直します。更新間隔の下限は16ミリ秒です。
- **スクロール時の進行**。マップをスクロールしている間も都市の時間が進みます。ゲーム内の速度設定と一時停止は引き続き使えます。
- **旧ウェブサイトへのリンク**。メニューの「ファラオのウェブサイトへ」ボタンから外部サイトを開く処理を無効にしました。
- **適用対象の確認**。対象CDの元の実行ファイルとv1適用済み実行ファイルをSHA-256で識別し、v2への更新後もSHA-256を照合します。

## 動作確認

Windows 11（ビルド26300、日本語システムロケール）でCDイメージから新規インストールし、v2の1920×1080全画面表示で最初のミッション「ヌブト」に入りました。メニュー、ミッション説明、チュートリアル、都市画面の日本語表示を確認しました。v1からの更新では、更新前後でセーブファイルのSHA-256が一致することを確認しました。

「ヌブト」で約3秒間ずつ、都市シミュレーションの更新回数を計測しました。表の数値はゲーム内の時間進行に対応する更新回数です。

| ゲーム内の速度設定 | 静止時 | スクロール入力中 |
| --- | ---: | ---: |
| 90% | 約45回/秒 | 約45回/秒 |
| 100% | 約63回/秒 | 約63回/秒 |

都市での速度検証は、上記の環境、ミッション、速度設定で行いました。
